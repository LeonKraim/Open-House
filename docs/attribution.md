# Attribution

Attribution owed to the reference repositories this corpus draws from. This
file is generated from [`catalog/licenses.yaml`](../catalog/licenses.yaml) by
`tools/catalog/attribution.py`, and is compared against a fresh regeneration
on every run: a hand edit is overwritten rather than kept, and a record change
whose regeneration was not committed fails the build. Do not edit it.

Each entry names a repository, its author, the licence its code and its prose
are under, the obligations those licences attach, and what the corpus takes
from it. Where a repo grants nothing, what may be taken is stated as what it
is, because the record's derived status is the whole of the answer.
